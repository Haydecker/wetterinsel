# Contributing / Mitmachen

**EN:** Issues and pull requests are welcome. Please keep changes small and focused, run `npm run build:single` (type-check + build) before opening a PR, and do not add tracking, analytics or additional third-party services without discussion. By contributing you agree that your contribution is licensed under Apache-2.0.

**DE:** Issues und Pull Requests sind willkommen. Bitte Änderungen klein und fokussiert halten, vor dem PR `npm run build:single` (Typprüfung + Build) ausführen und kein Tracking, keine Analyse-Dienste und keine weiteren Drittdienste ohne Absprache ergänzen. Mit deinem Beitrag stimmst du zu, dass er unter Apache-2.0 steht.
